# South Jersey Seller's Guide

A static guide to selling a home in Atlantic, Cape May, Cumberland, Salem, Gloucester, Camden, Burlington and Ocean counties, NJ.

* `python3 build.py` builds the site from `data/*.json` and `site/` into `docs/`.
* Env vars: `BASE` (origin, default `http://localhost:8000`), `PATH_PREFIX` (e.g. `/sj-seller-guide`), and `FORM_ID` (Formspree id; the signup stays disabled when it's unset).
* Preview locally: `python3 build.py && cd docs && python3 -m http.server 8000`
* Deploy: `.github/workflows/pages.yml` builds docs/ fresh in CI (docs/ is git-ignored) and deploys it with GitHub Pages Actions.

## Data
* `data/municipalities.json`: all 201 municipalities from the Census 2020 county-subdivision file (Pine Valley merged into Pine Hill in 2022), with 2025 tax rates, 2026 equalization ratios and the NJ.gov website link. Generated by `tools/make_data.py` from `data/raw/`.
* `data/towns_verified.json`: hand-verified resale CO / certificate rules. Each entry has `status` (verified|partial), a `checked` date and `sources`. **Never add a fact without an official source** (municipal site, municipal code, or official form).
* `data/statewide.json`: rate tables (asserted by tests in build.py) and source URLs.

## Updating a town
Add or edit an entry in `data/towns_verified.json` keyed by slug, set `checked` to today's date, rebuild, and commit.

Not legal advice.
